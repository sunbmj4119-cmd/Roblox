# ☄️ Meteor Rush (운석 러시)

**운석이 떨어진다! 다 같이 깨부수고, 쏟아진 별알을 들고 집까지 튀어라!**
약 3분마다 서버 어딘가(광장 · 집들 사이 큰길 · 광산)에 운석이 떨어지고, 모두가 함께 부순 뒤 쏟아진 별알을 들고 집으로 달리는 로블록스 게임입니다. 집에 가져온 별알은 돈을 버는 펫이 되고, 집은 🌙 도둑의 밤에만 털 수 있습니다.

## ☄️ v19 Meteor Rush (현재 버전)
- **한 판 ≈ 3분**: 휴식 120초 → ⚠️ 경고 20초(낙하 지점에 붉은 원 + 빛기둥 + 카운트다운, `가자` 버튼은 경고 중에만) → 쾅! → 다 같이 부수기(최대 50초) → 별알 · 코인 덩어리 · 가끔 럭키 블록이 쏟아짐 → 집까지 달리기
- **낙하 장소**: 광장 35% / 집들 사이 큰길 25% / 광산 구역 40% (서버에서 열린 구역 중). 소환 운석은 소환한 사람이 있는 곳에 떨어짐
- **운석 종류 = 알 종류** (🌿초원 ❄️얼음 🔥용암 🔮공허 🌌우주), **크기** 작은/큰/거대(알 +0/+1/+3), **✨ 황금 운석** 8% (알 행운 2배, 코인 3배)
- **순위**: 1등은 Epic 이상 알을 5초 먼저, 2~3등도 1개씩 먼저. 가장 좋은 알 2개에는 수호자가 붙음
- **운석 도감**: 종류마다 처음 깨면 💎50. 칭호 ☄️ 운석 사냥꾼(25번 참가) · 🌠 별알 배달부(25개 배달)
- **🏠 집은 안전**: 남의 펫 훔치기는 🌙 도둑의 밤(이벤트 3번에 1번, 20초 전 예고, 2분)에만. 금고 수입 100%
- **첫 1분**: 나만의 작은 운석 → 별알이 튀어나옴 → 줍기 → 집으로 → 부화 → 채굴 → 곡괭이 (기존 튜토리얼 진행 중이던 저장 데이터는 새 튜토리얼로 다시 시작)
- 🎉 주간 파티 때는 다음 운석이 **거대 황금 운석**

## 🌄 v23 월드 리뉴얼 + 라이벌의 집
- **지형**: 평평한 판 대신 로블록스 지형 — 잔디/눈/현무암/슬레이트/용암 바닥, 벽 대신 울퉁불퉁한 바위 절벽, 멀리 언덕과 나무, 구름, Future 조명
- **광석**: 정육면체 대신 그 구역 돌로 된 바위 + 보석은 결정, 금속은 덩어리가 박힌 모양. 촘촘한 격자 대신 광맥(덩어리) 단위로 배치 → 길이 생김
- **운석**: 울퉁불퉁한 바위 껍질 + 빛나는 용암 균열 + 연기·불씨·불꽃 꼬리, 떨어지면 충격파·먼지·검게 탄 크레이터
- **집**: 집 사이 간격 2배 이상(나무 줄 + 잔디 언덕), 담장을 낮춰 카메라가 안 가려짐, 조명 덜 눈부시게
- **라이벌의 집**: 라이벌도 빈 땅에 집을 짓고 펫을 전시. 🌙 도둑의 밤엔 내가 라이벌 집을 털 수 있고(주인이 쫓아옴), 라이벌도 내 전시 펫을 훔치러 옴(경보 → 때려서 막기, 가져가면 5분 복수). 라이벌이 나가면 가져간 펫은 돌려줌

## 🌱 v22 키우기 · ⭐ 진화 · 📖 도감 · ☄️ 운석 펫 · 사람 같은 라이벌
- **🌱 펫 성장**: 모든 펫이 레벨 1~10 (🍼 아기 → 🐣 어린이 → ⭐ 어른 → 👑 전설, 눈에 보이게 커짐). 경험치: 따라다니며 도울 때(펫 도우미 한 번 +2), 운석을 같이 부쉈을 때(+30), 별알 배달(+15), 집에 서 있을 때(1분 +1), ✨ 별가루 먹이(레벨의 25%). 레벨마다 수입·힘 +15% (Lv10 = x2.35)
- **⭐ 진화**: Lv10 펫 + 같은 펫 2마리 → ★ (수입·힘 x2, 최대 ★★★ = x8), 다시 Lv1부터. 별 후광 + 크기 커짐. 중복 펫이 쓸모 생김 (Adopt Me 네온 / PS99 퓨즈 방식)
- **📖 도감**: 모든 펫을 알별로, 못 찾은 건 ?로 표시. 5·10·15…40마리 달성 시 💎 + **영구 집 수입 보너스**, 알 세트 완성마다 +3%
- **☄️ 운석 펫 5종**: 운석에서 나온 별알에서만 부화 (혜성 토끼 / 오로라 여우 / 운석 드레이크 / 성운 위습 / 별똥별 타이탄). 별알 등급이 높을수록, 황금 운석이면 2배 확률
- **라이벌 = 사람 같은 플레이어**: 로블록스 공식 무료 아이템으로 만든 평범한 아바타, 이름·레벨·칭호·곡괭이·따라다니는 펫, 걷기/휘두르기 애니메이션. 평소엔 채굴, 운석 경고엔 달려가고(멀면 GO처럼 순간이동), 같이 부수고, 남은 별알을 들고 집으로 뛰고, 가끔 별알 든 플레이어를 때림 (새 플레이어 첫 알·스폰 근처·집 구역은 안 됨). 가짜 채팅·가짜 입장 메시지·실제 계정 사용은 하지 않음

## 🤖 v21 혼자서도 재밌게 + 펫 도우미 + 눈부심 완화
- **🤖 라이벌 로봇**: 서버에 실제 플레이어가 1~2명뿐이면 호버 로봇 2대가 등장. 운석 경고가 뜨면 같이 달려가고, 같이 부숴서 순위 경쟁(플레이어의 60% 속도), 터진 뒤 5초 넘게 아무도 안 주운 별알을 들고 14초 뒤 날아가 버림 → 때리면 기절 + 별알 떨어뜨림 + 코인. 예약 알(튜토리얼·1~3등)과 수호자 알은 안 건드리고, 집 구역엔 안 들어감. 3명 이상이 되면 다음 쉬는 시간에 떠남
- **🐾 펫 도우미**: 따라다니는 펫(가장 강한 펫 N마리 = 기본 3, 환생 5번마다 +1, 펫 슬롯 패스 +3, VIP +1)이 내가 채굴/운석을 칠 때 1.2초마다 근처 광석이나 운석으로 뛰어가 같이 때림 (펫 1마리 = 내 한 방의 25%). 8초 넘게 안 치면 쉼(잠수 방지)
- **눈부심 완화**: 블룸 약하게(밝은 흰색/금색 표면이 번지지 않게), 반사광·노출 낮춤, 벽 윗부분 네온 제거, 펫/광석 빛 약하게, 받침대 색 차분하게

## 🚀 빠른 시작

### 방법 A: 플레이스 파일 바로 열기 (가장 쉬움)
1. 저장소에 포함된 `MeteorMiners.rbxlx`를 Roblox Studio에서 엽니다.
2. **Play** (F5)를 누르면 끝입니다.
3. 코드를 고친 뒤에는 [Rojo](https://rojo.space)로 다시 빌드합니다.
   ```bash
   rojo build default.project.json -o MeteorMiners.rbxlx
   ```

### 방법 B: Rojo 실시간 동기화 (개발용)
1. Studio에 Rojo 플러그인을 설치합니다.
2. 터미널에서 `rojo serve`를 실행합니다.
3. Studio의 Rojo 플러그인에서 **Connect**를 누릅니다.
4. Workspace의 `StreamingEnabled`를 **꺼 주세요** (클라이언트가 게이트와 광석을 직접 참조합니다).
5. 기본 템플릿(Baseplate)에서 시작했다면 기본 `Baseplate`와 `SpawnLocation`은 삭제하세요. 맵은 서버가 시작할 때 자동으로 생성됩니다.

### Studio 테스트 팁
- **Game Settings → Security → Enable Studio Access to API Services**를 켜면 DataStore 저장과 리더보드가 동작합니다. 꺼져 있어도 임시 데이터로 플레이할 수 있습니다.
- 상품 ID가 `0`인 상태에서는 **Studio에서 구매가 즉시 시뮬레이션됩니다** (`[TEST]` 표시). 모든 결제 흐름을 실제 상품을 만들기 전에 테스트할 수 있습니다.
- 화면 왼쪽 아래 **🛠 DEV** 버튼(Studio에서만 보임)으로 코인·젬·랭크 점수·시즌 XP를 지급하고, 운석을 즉시 소환하고, 별/조각을 테스트하고, 데이터를 초기화할 수 있습니다. 라이브 서버에서는 서버가 차단합니다.
- 운석이 빨리 보고 싶다면 DEV → Meteor를 누르거나 `Config.Meteor.IntervalSeconds`를 줄이세요. 서버 시작 후 첫 운석은 최대 150초 뒤에 떨어집니다.
- 설정 검증: [Lune](https://lune-org.github.io/docs)을 설치한 뒤 `lune run tests/ConfigCheck.luau`를 실행하면 펫·광석·상품 이름 오타와 확률 합계를 검사합니다.
- 번역 검증: `python3 tests/lang_keys.py`(코드의 모든 문구가 `src/shared/LangKO.luau`에 있는지 + `%s`/`%d` 순서 일치)와 `lune run tests/LangCheck.luau`(실제 포맷 동작). `tools/publish.sh`는 이 검사가 실패하면 게시하지 않습니다.

### 🌐 언어 (한국어 / English)
- 모든 문구는 영어 원문을 키로 쓰고 `src/shared/LangKO.luau`에서 한국어로 바꿉니다. 로블록스 언어가 한국어인 유저는 자동으로 한국어, 그 외는 영어로 보입니다.
- 게임 안 **⚙️ 설정 → 🌐 언어**에서 자동/한국어/English를 직접 고를 수 있습니다 (저장 후 자동 재접속).
- 새 문구를 추가하면 `python3 tests/lang_keys.py`가 빠진 번역을 알려 줍니다. 한국어 문장에서도 `%s`, `%d`의 **개수와 순서**는 영어와 같아야 합니다.

### 🌠 별 조각 + 🏠 기지 (핵심 루프)
- 40~70초마다 **별이 떨어지고**(빛기둥 표시), 운석을 부수면 조각이 쏟아집니다. 1등은 영웅 이상 조각을 5초간 독점.
- 조각을 주우면 머리 위에 들고 **느려지며, 누구나 때려서 떨어뜨릴 수 있습니다**(스폰 근처 제외). 허브 남쪽 **기지 구역**의 내 기지에 들어가면 진열대에 놓입니다.
- 진열된 조각은 **매초 코인**을 기지 금고에 쌓습니다(오프라인 50%, 최대 2시간). 초록 발판을 밟아 받기, 빨간 발판은 60초 잠금.
- 다른 사람 기지의 조각을 **길게 눌러 훔칠 수** 있고, 주인은 도둑을 때려 되찾습니다(떨어진 조각은 10초 뒤 자동 귀환).
- 진열대 추가 구매(코인), 조각 판매 가능. 수치는 `Config.Shards`, `Config.Base`.
- **서버 인원은 8명**입니다(영토 8개, 큰 길을 사이에 두고 두 줄). Steal a Brainrot 등 인기 기지형 게임과 같은 인원이라 한 명당 넓은 영토를 줄 수 있고 폰에서도 부드럽습니다. 사람이 차면 Roblox가 서버를 새로 열기 때문에 전체 동시접속은 무제한입니다. 바꾸려면 `Config.Base.Plots`와 Creator Dashboard → Places → Server size를 같은 숫자로 맞추세요(`Config.Base.Layout`이 배치를 계산합니다).

### 🐾 v12 핵심 루프: 펫이 기지에서 돈을 번다
- **펫 = 기지 수익원.** 가장 많이 버는 펫부터 기지 진열대에 서서 **매초 코인**을 법니다(꾸미기에서 진열대를 더 놓으면 더 많이 진열). 나머지는 📦 보관함. 가장 강한 펫들은 자동으로 따라다니며 채굴 파워를 더해 줍니다(장착 버튼 없음).
- **알 재입고(5분마다):** 코인 알(초원/서리/용암/공허)은 5분마다 재고가 바뀝니다. 모든 서버가 같은 재고라 "공허 알 입고!" 같은 순간이 생깁니다. 젬/별가루/로벅스 알은 항상 판매.
- **변이:** 황금(수익 3배), 무지개(8배), 은하(12배, 유성우 때 확률↑), 얼음(❄️ 눈보라 때), 용암(🔥 폭염 때).
- **별 알:** 떨어지는 별과 운석은 이제 **별 알**을 떨어뜨립니다. 기지로 가져가면 그 자리에서 부화(별 등급이 높을수록 행운↑, 떨어진 구역의 알 종류).
- **펫 훔치기:** 남의 기지 진열대의 펫을 길게 눌러 훔치고 내 기지까지 달려가면 내 펫이 됩니다. 함정/때리기로 막을 수 있음.
- **거래:** 펫 화면 → 🤝 거래 → 같은 서버 유저 선택. 최대 4마리씩, 둘 다 준비 → 3초 후 교환(바꾸면 준비가 풀려 사기 방지).
- **게임 방법 카드:** 첫 접속 시 1번, 설정의 ❓로 다시 보기.
- 펫 판매 = 1분치 수익. 수치: `Config.Pets`(Income), `Config.PetVariants`, `Config.Eggs[...].Stock`, `Config.Shop`.

## 📱 폰으로 테스트하면서 업데이트하기 (PC 없이 반복)

게임이 로블록스에 한 번 올라가면, 그다음부터는 **Studio 없이** 새 버전을 올릴 수 있습니다 (Open Cloud Place Publishing API).

1. **최초 1회:** 게임(experience)을 만들어 공개합니다. PC Studio에서 한 번 Publish하거나, 아이폰이라면 Build 앱으로 아무 게임이나 하나 만들어 올려도 됩니다. 그 게임에 이 파일을 덮어씁니다.
2. **API 키 만들기 (폰 브라우저 가능):** Creator Hub → Open Cloud → API Keys → Create API Key
   - Access Permissions: **universe-places** 추가 → 이 게임 선택 → **Write**
   - Accepted IP Addresses: `0.0.0.0/0` (업로드하는 서버 IP가 고정이 아님)
   - 만료일: 30~90일
3. **Universe ID와 Place ID 확인:** Creator Hub에서 게임을 열면 주소창 URL에 숫자로 나옵니다.
4. **배포:** `ROBLOX_API_KEY=키 tools/publish.sh <UniverseId> <PlaceId>`를 실행합니다. Claude 세션에서는 키를 채팅에 쓰지 말고 보안 입력창으로 넣습니다.
5. **확인:** 폰에서 게임을 나갔다가 다시 들어가면 새 버전입니다. 옛 서버가 남아 있으면 Creator Hub의 서버 재시작 메뉴를 쓰세요.

**폰에서 에러 보는 법:** 게임 메뉴 → Settings → **Developer Console → Open** (채팅에 `/console`을 쳐도 됨). 게임 주인은 서버 로그도 볼 수 있습니다. 에러 화면을 **스크린샷으로 보내 주면** 고칠 수 있습니다. Creator Hub → Monitoring → **Error Report**에도 에러가 모입니다.

**오너 테스트 모드** (`Config.OwnerTestMode = true`): 게임 주인에게는 라이브 서버에서도 🛠 DEV 버튼이 보이고, ID가 아직 0인 상품은 **로벅스 차감 없이 테스트 구매**됩니다. 주인 점수는 글로벌 리더보드에 올라가지 않습니다. **정식 오픈 전에 반드시 false로 바꾸세요.**

## 💰 출시 전 수익화 설정 (필수)

## 🔐 보안 & 데이터 무결성
- 모든 재화 변경은 **서버에서만** 처리합니다. 클라이언트는 "요청"만 보냅니다.
- 채굴은 서버가 사거리(13 studs)와 쿨다운을 검증하고, PvP는 거리·구역·무적 시간을 검증합니다.
- 모든 리모트 액션에 레이트 리밋이 걸려 있고 `pcall`로 보호됩니다.
- `ProcessReceipt`는 PurchaseId를 저장해 **중복 지급을 막고**, 지급 직후 저장합니다.
- 세션 락으로 서버를 빠르게 옮겨 다니며 아이템을 복사하는 것을 막습니다.
