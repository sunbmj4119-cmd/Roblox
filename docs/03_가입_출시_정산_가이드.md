# 03. 가입 · 게임 올리기 · 정산 가이드 (2026년 11월 기준)

> 로블록스 규정은 자주 바뀝니다. 아래 숫자는 조사 시점 기준이므로 실제 진행 전에 Creator Hub 안내를 한 번 더 확인하세요. 출처는 맨 아래에 있습니다.

## 0. 돈이 흐르는 구조 한눈에 보기

```
유저가 현금으로 Robux 구매 (Roblox가 판매)
        │
        ▼
유저가 우리 게임에서 Robux로 게임패스·상품 구매
        │  Roblox 수수료 30%
        ▼
내 계정에 70%가 Robux로 적립 ── 처음 며칠은 "대기(pending)" 상태
        │
        │  + 크리에이터 리워드 (Roblox가 따로 지급, 60일 보류 후 적립)
        ▼
"Earned Robux"가 30,000개 이상 쌓이면
        │
        ▼
DevEx(개발자 환전) 신청 → 1 Robux = $0.0038 → Tipalti를 통해 은행 계좌로 달러 송금
```

**감 잡기용 계산**
- 유저가 R$299짜리 VIP를 사면 → 내 몫 약 209 Robux → 약 **$0.80**
- 환전 최소 기준 30,000 Robux = 약 **$114**
- 대략적으로 유저가 쓴 현금의 **20% 안팎**이 개발자에게 옵니다. Robux 구매 가격은 패키지마다 달라서 정확한 비율도 달라집니다.

## 1. 가입 (PC 권장)
1. roblox.com에서 가입합니다. **생년월일은 실제 나이로** 입력하세요. 환전은 13세 이상이어야 하고, 나중에 신분증 인증을 할 때 나이가 맞아야 합니다.
2. **이메일 인증**을 합니다 (환전 필수 조건).
3. **2단계 인증**을 켭니다 (설정 → 보안). 전체 연령 공개에 필요합니다.
4. **연령 확인 / 신분증 인증**을 합니다 (설정 → 계정 정보). 얼굴 나이 추정이나 신분증(여권 등)으로 합니다. 게임 공개에 필요합니다.
5. Roblox Studio를 설치하고 같은 계정으로 로그인합니다 (Windows/Mac).

> 혼자 하면 개인 계정으로 올려도 됩니다. 팀·회사로 운영할 계획이면 **그룹**을 만들어 그룹 소유로 올리는 것이 좋습니다. 그룹 매출은 그룹 금고에 쌓이고, 그룹 주인이 멤버에게 분배할 수 있습니다. 그룹 소유 게임은 그룹 주인이 출시 조건을 갖춰야 합니다.

## 2. 게임 올리기
1. Studio에서 `MeteorMiners.rbxlx`를 열고 **Play**로 테스트합니다.
2. **File → Publish to Roblox**에서 새 게임을 만듭니다 (이름, 설명).
3. **Game Settings → Security → Enable Studio Access to API Services**를 켭니다. 저장과 리더보드가 동작합니다.
4. Creator Hub(create.roblox.com)에서 아래를 설정합니다.
   - 아이콘, 썸네일, 설명, 장르
   - **Maturity & Compliance 설문**: 콘텐츠 등급을 정하는 설문입니다. 공개 필수입니다.
   - 공개 여부를 **Public**으로 바꿉니다.
5. **상품 만들기:** Monetization → Passes(게임패스 10개)와 Developer Products(16개)를 만들고 가격을 정합니다. 생성된 ID를 `src/shared/Config.luau`에 넣고 다시 Publish합니다. 이 작업은 저에게 ID만 알려 주셔도 됩니다.

### 2026년 공개 규정: 누구에게 보이나
| 노출 대상 | 필요 조건 |
|---|---|
| **16세 이상** | 가입 후 2일 이상 지난 정상 계정 + 연령 확인 + 콘텐츠 설문 |
| **전체 연령** (5~8세 Kids, 9~15세 Select 포함) | 위 조건 + **신분증 인증** + **2단계 인증** + (**Plus 또는 Premium 2개월 연속 구독** 또는 **게임당 1,000 Robux 수수료**. 수수료는 3개월 뒤 환불) + 게임별 평가 (일정 수 이상 유저가 꾸준히 플레이해야 한다는 기준이 있음) |

👉 이 게임의 주 타깃은 9~16세입니다. **처음에는 16세 이상 대상으로 출시**해서 유저를 모으고, 조건을 갖춘 뒤 전체 연령 노출을 신청하는 순서가 현실적입니다.

## 3. 정산 (돈 받기)
### 수익원 3가지
1. **판매 수익 (가장 큼):** 게임패스·개발자 상품·비공개 서버 판매가의 **70%**를 Robux로 받습니다. 결제 후 며칠간은 "대기" 상태로 묶였다가 사용할 수 있는 Robux가 됩니다. 사기 결제를 막기 위한 장치입니다.
2. **크리에이터 리워드 (Roblox가 따로 주는 보너스):**
   - 최근 60일간 $9.99 이상 쓴 유저가 그날 처음 플레이한 게임 3개 안에 내 게임이 있고, 거기서 **10분 이상** 놀면 하루 **5 Robux**를 받습니다.
   - 로블록스 **신규·복귀 유저를 데려오면**, 그 유저가 첫 2개월 동안 쓴 금액(최대 $100)의 **35%**를 받습니다. 유튜브·틱톡 홍보 링크가 중요한 이유입니다.
   - 이 돈은 **60일 보류** 후에 적립됩니다.
3. **보상형 동영상 광고:** 자격을 갖춘 뒤 켜면 광고 수익이 생깁니다 (현재 게임에서는 꺼 둠).

### 현금으로 바꾸기 (DevEx)
1. 조건: 13세 이상, 이메일 인증, 정상 계정, **Earned Robux 30,000개 이상**
2. Creator Hub → **DevEx**에서 환전을 신청합니다 (한 달에 1번).
3. 첫 신청 때 **Tipalti**(로블록스의 송금 대행사) 초대 메일이 옵니다. **1주일 안에** 아래 두 가지를 입력해야 합니다.
   - **은행 계좌 정보**
   - **세금 서류 W-8BEN** (미국 외 개인용. 한국 거주자는 한미 조세조약 혜택을 적용할 수 있음)
4. 심사가 끝나면 달러로 송금됩니다. 환율은 $0.0038/Robux이고, 조건을 갖춘 게임에서 미국 18세 이상 유저가 쓴 금액은 +42%입니다.

### 세금 ⚠️
- **2026년 11월 1일부터** DevEx 지급금은 "로열티"로 분류됩니다. 해외 개발자는 미국 세금 서류 **1042-S**를 받고, 미국에서 세금이 먼저 떼일 수 있습니다. 세금 서류는 Creator Hub의 Taxes 페이지에서 관리합니다.
- 한국에서는 이 수입을 **종합소득세로 신고**해야 하고, 미국에서 떼인 세금은 공제받을 수 있습니다. 금액이 커지기 전에 **세무사와 한 번 상담**하는 것을 권합니다 (개인으로 할지 사업자로 할지도 포함).

## 4. 현실적인 일정
| 시점 | 할 일 |
|---|---|
| 1일차 | 가입, 이메일·2단계 인증, 연령 확인, Studio 설치, 게임 테스트·비공개 업로드 |
| 3일차~ | 16세 이상 대상으로 공개, 상품 ID 입력 후 재배포, 홍보 시작 |
| 첫 판매 후 며칠 | 대기 기간이 끝나고 Robux 적립 |
| 30,000 Robux 도달 | DevEx 신청 → Tipalti 등록 → 송금까지 보통 수 주 |
| 유저가 모이면 | 신분증 인증 + 1,000 Robux(또는 구독)로 전체 연령 노출 신청 |
