# ☄️ Meteor Rush — 게임 기획서

> **한 문장:** 운석이 떨어진다! 다 같이 깨부수고, 쏟아진 별알을 들고 집까지 튀어라!
> **English:** A meteor is falling! Smash it together, grab the star eggs and run home!

## 1. 왜 이 방향인가
| 문제 (이전 버전) | 해결 |
|---|---|
| 별알 + 수호자 + 속도 + 지역 잠금이 1위 게임 *Steal An Egg* 와 거의 같음 | 알은 **하늘에서 떨어지는 운석**에서만 나옴 — 시간과 장소가 매번 다름 |
| 남의 집 털기가 기본 규칙 → 규칙이 복잡 (금고·보호막·복수·현상금·크기 차이) | **집은 기본적으로 안전.** 집 털기는 🌙 도둑의 밤 이벤트 때만 |
| 기능이 너무 많아서 "뭘 하면 돼?" | 모든 기능이 **운석 한 판(약 3분)** 을 중심으로 돌아감 |
| 첫 5분에 채굴부터 시킴 | 접속 20초 안에 **운석을 깨는 손맛**부터 |

운석을 중심으로 한 큰 Roblox 게임은 아직 없다 → 유사 게임 노출 축소(클론 판정)를 피하기 좋다.

## 2. 한 판 (서버 전체가 같은 박자)
| 단계 | 시간 | 내용 |
|---|---|---|
| 휴식 | 120초 | 채굴로 코인, 곡괭이·신발·집 강화, 부화, 꾸미기 |
| ① 경고 | 20초 | 하늘에 **낙하 지점 표시**(붉은 원 + 빛기둥 + 카운트다운). 모두 달려감. `가자` 버튼은 경고 중에만 그 구역 입구로 순간이동 |
| ② 낙하 | 2초 | 쾅! 화면 흔들림 |
| ③ 깨기 (협동) | 최대 50초 | 곡괭이로 다 같이 때림. 참가자가 늘수록 체력이 늘어서 사람이 적어도 많아도 30~40초 |
| ④ 쏟아짐 (쟁탈) | — | 별알, 코인 덩어리, 가끔 럭키 블록. 기여 1~3위는 몇 초 먼저 주울 수 있음 |
| ⑤ 귀환 (추격) | — | 별알을 들고 집으로. 희귀 알은 운석 몬스터가 쫓아옴. 다른 사람이 때리면 떨어뜨림 |

### 낙하 장소
| 장소 | 확률 | 비고 |
|---|---|---|
| 광장 | 35% | 누구나 갈 수 있음 |
| 집들 사이 큰길 | 25% | 우리 동네에 떨어지는 느낌 |
| 광산 구역 | 40% | 서버에서 누군가 열어 둔 구역 중 하나. 깊을수록 좋은 알 |

광장·큰길 운석의 알 종류는 서버에서 가장 깊이 간 구역까지 중 무작위.
☄️ 운석 소환(유료)은 **소환한 사람이 있는 곳**(광장 / 큰길 / 그 사람의 광산)에 10초 경고 후 떨어진다.
큰길 운석의 별알과 코인은 남의 마당이 아니라 **길을 따라** 흩어진다.

### 운석 종류 (= 알 종류)
| 운석 | 알 |
|---|---|
| 🌿 초원 운석 | Meadow |
| ❄️ 얼음 운석 | Frost |
| 🔥 용암 운석 | Lava |
| 🔮 공허 운석 | Void |
| 🌌 우주 운석 | Cosmic |

### 크기
| 크기 | 확률 | 반지름 | 체력 | 별알 |
|---|---|---|---|---|
| 작은 | 55% | 7 | ×0.7 | 기본 |
| 큰 | 33% | 9 | ×1 | +1 |
| 거대 | 12% | 12 | ×1.6 | +3, 1등 보상 Epic 이상 |

✨ **황금 운석** (8%, 크기와 별개): 알 행운 2배, 코인 덩어리 3배, 서버 공지.

### 쏟아지는 것
- 별알 = 3 + 참가 인원 (+크기 보너스), 최대 10개. 1등은 Epic 이상 1개를 5초 먼저, 2~3등은 1개씩 4초 먼저
- 가장 좋은 알 2개에는 운석 몬스터(수호자)
- 코인 덩어리 8개 (황금 운석이면 3배): 밟으면 바로 코인 (내 기지 수입 × 12초, 최소 150)
- 30% 확률로 🍀 럭키 블록
- 순위 보상(별가루·보석·주간 점수)은 그대로

### 운석 도감
운석 종류마다 처음 깰 때 💎50과 도감 등록. 칭호: ☄️ 운석 사냥꾼(운석 25개 참가), 🌠 별알 배달부(별알 25개 배달).

## 3. 규칙
1. **내 집은 항상 안전하다.** 펫이 받침대에서 돈을 번다 (오프라인 50%, 최대 2시간).
2. **쟁탈은 현장에서만:** 별알을 든 사람은 맞으면 떨어뜨린다. 집에 도착하면 부화.
3. **🌙 도둑의 밤** (이벤트 3번에 1번, 약 20분마다, 2분간): 20초 전에 예고. 그동안만 남의 전시대 펫을 훔칠 수 있다. 🔒 금고 펫, 💎 한정 펫, 초보 보호는 그대로 안전하고 복수·현상금 규칙이 적용된다. 훔치면 보너스 코인.
4. 금고 받침대는 이제 **수입 100%** (도둑의 밤에도 안전한 자리).

## 4. 성장 (메인 3가지)
| 강화 | 효과 |
|---|---|
| ⛏️ 곡괭이 | 운석을 더 세게 → 순위↑ → 좋은 알 우선권. 광석 채굴도 빨라짐 |
| 👟 신발 | 운석에 먼저 도착하고 별알 들고 더 빨리 도망 |
| 🏠 집 레벨 | 꾸밀 땅·금고·장식 수, 집 모양 |

보조: 구역 해금(깊은 운석), 환생, 펫(따라다니며 힘 보탬), 칭호, 꾸미기, 교환.

## 5. 목표
| 기간 | 목표 |
|---|---|
| 이번 판 | 운석 깨기 → 별알 1개 이상 집으로 (+1~3위 보상) |
| 오늘 | 운석 도감 채우기, 일일 퀘스트(운석 참가·Top3·배달), 일일 보상 |
| 장기 | 깊은 구역 운석, 거대·황금 운석, 타이타닉 펫, 집 레벨 5, 주간 ☄️ 운석 헌터 랭킹 |

HUD 목표 우선순위: 들고 있음 → 운석 경고 → 운석 깨는 중 → 바닥의 별알 → 기지 저금 수령 → 강화 → "다음 운석까지 채굴하며 준비".

## 6. 첫 5분
| 시간 | 단계 (튜토리얼) | 보상 |
|---|---|---|
| 0:00 | ☄️ **나만의 작은 운석**이 광장에 떨어짐 → "때려 부숴요!" (혼자 8번 정도) | 💰100 |
| 0:25 | 🥚 별알이 튀어나옴 → "주워요!" (나만 먼저 주울 수 있음) | — |
| 0:35 | 🏠 "집으로 달려요!" (빛줄기 안내) → 도착하면 부화 카드 | 💎30 |
| 1:20 | ⛏️ 광석 5개 채굴 | 💰150 |
| 2:00 | 🛒 돌 곡괭이 구매 ("운석을 더 세게!") | 💰300 |
| 2:30 | 끝 → 💎100 + 코인 2배 10분. 첫 진짜 운석(접속 후 약 1분) 경고가 곧 울림 | |

기존에 튜토리얼 중이던 저장 데이터는 새 튜토리얼 1단계부터 다시 시작한다.

| 처리 | 시스템 |
|---|---|

## 8. 라이브 운영 (매주 토요일)
- 새 **운석 종류 1개** + 전용 펫 4~5종 (예: 🍬 캔디, 🧊 크리스탈, 👾 외계, 🎃 할로윈)
- 토요일 20:00(KST) 🎉 주간 파티: 럭키 블록 비 + 유성우 + 행운 2배 + 다음 운석은 **거대 황금 운석** (모든 서버 동시)
- 관리자 이벤트: DEV 패널 `Party`

## 10. 확인할 지표 (실제 유저)
첫 플레이 이탈률, 1일 재방문(목표 20%+), 평균 플레이 시간(목표 15분+), 운석 참가율(판당 서버 인원의 60%+), 운석 1판 길이, 별알 배달 성공률(40~70%).
