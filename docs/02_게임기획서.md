# 02. 게임 기획서: Meteor Miners (메테오 마이너즈)

> **한 줄 요약:** 광석을 캐서 팔고, 펫을 뽑아 강해지고, **7분마다 떨어지는 운석을 서버 전체가 쟁탈**하며 **매주 리셋되는 랭크**에서 1위를 다투는 채굴 시뮬레이터.

## 1. 타깃 & 포지셔닝
- **타깃:** 9~16세 로블록스 핵심층. 모바일 비중이 높아서 UI 전체를 모바일 우선으로 스케일링했습니다.
  - ⚠️ 2026년 출시 규정상 처음에는 **16세 이상**에게만 노출됩니다. 9~15세(Roblox Select)까지 열려면 ID 인증, 2단계 인증, Plus/Premium 2개월 또는 게임당 1,000 Robux(환불형), 게임 평가를 통과해야 합니다 → [03. 가입·출시·정산 가이드](03_가입_출시_정산_가이드.md)
- **장르:** 시뮬레이터 (Mining Simulator 계열) + 서버 이벤트 (Grow a Garden 계열) + 라이트 PvP 약탈 (Steal a Brainrot 계열)
- **차별점:** 기존 채굴 시뮬레이터는 혼자 성장하는 게임입니다. 이 게임은 **매 7분 서버 레이드**와 **활동량 기반 주간 랭크**로 "계속 경쟁하는" 구조를 만들었습니다.

## 4. 경쟁 시스템 상세

### 4-1. ☄️ 운석 레이드 (서버 이벤트)
- **주기:** 7분 (`Config.Meteor.IntervalSeconds`). 30초 전에 서버 전체 공지가 나가고 화면 상단에 카운트다운이 항상 표시됩니다.
- **판정:** 타격 점수 = `1 + log10(데미지)`. 데미지 1인 신규 유저는 1점, 데미지 1만인 고수는 5점이라 격차가 5배로 압축됩니다. **신규 유저도 상위 3위가 가능**하도록 설계했습니다.
- **운석 체력 자동 조절:** 새 참여자가 처음 때릴 때마다 "그 유저가 약 40초 동안 때릴 분량"만큼 체력이 늘어납니다. 그래서 초보만 있는 서버든 고수가 많은 서버든 이벤트가 비슷한 길이(약 40~60초)로 끝나고, AFK 유저는 체력에 영향을 주지 않습니다.
- **보상:** 1위 400✨+100💎, 2위 250✨+60💎, 3위 150✨+40💎. 참여자 전원은 기여도 비례로 받고, 실패 시 50%를 받습니다.
- **실시간 순위 패널**과 결과 팝업이 경쟁 심리를 자극합니다.
- **수익 연결:** "운석 소환" 상품(R$99)을 사면 즉시 이벤트가 시작되고 구매자는 스타더스트를 2배로 받습니다. 서버 전체에 공지가 나가서 다른 유저들이 몰려옵니다.

### 4-2. 🏆 주간 랭크
- **점수원:** 블록 채굴(구역별 1~6점), 운석 순위, 퀘스트, PvP 타격. **보유 재화가 아니라 활동량**이 기준이라 과금 고래가 독식하지 못하고 매주 새로 경쟁할 수 있습니다.
- **티어:** 브론즈 0 / 실버 500 / 골드 2,000 / 플래티넘 6,000 / 다이아 15,000 / 마스터 35,000
- **보상:** 주가 바뀌면 지난주 티어 보상(최대 2,500💎)과 **글로벌 Top 10 보상**(1위 5,000💎)을 지급합니다.
- **과시:** 머리 위에 랭크가 표시되고, 주간 1~3위는 👑🥈🥉 칭호, Top 10은 ⭐ 칭호를 받습니다(채팅 태그 포함). 랭크가 다이아 이상으로 오르면 서버 전체에 공지됩니다.

### 4-3. 📊 글로벌 리더보드 (허브 대형 전광판)
주간 랭크(매주 리셋), 최고 부자(누적 코인), 최다 환생 세 가지입니다. OrderedDataStore 기반이고 90초마다 갱신됩니다.

### 4-4. ⚔️ PvP 약탈 (Star Crater)
가장 비싼 광석이 나오는 구역은 위험한 구역입니다(리스크와 보상). 곡괭이로 상대를 클릭하면 넉백되고 상대 가방의 25%가 오브로 떨어집니다. 맞은 유저는 4초간 무적이라 연속 사냥은 막힙니다. 일일 퀘스트 "5명 때리기"로 PvP 참여를 유도합니다.

### 5-3. 기타 수익원
- **Miner Club 구독** (월정액): 코인 +20%, 매일 150💎, [CLUB] 태그
- **Roblox Premium:** Premium 회원 코인 +10% (Premium 회원 우대 혜택).

- **비공개 서버:** Studio의 Game Settings에서 유료로 켜면 됩니다.

### 5-4. 과금 설계 원칙
1. **결정적 순간에 업셀.** 가방이 찼을 때, 슬롯이 꽉 찼을 때, 3연차를 누를 때처럼 필요한 순간에 바로 제안합니다(같은 제안은 90초 쿨다운으로 피로도를 막음).
2. **과시는 무료로 공개.** 희귀 펫 부화, 패스 구매, 서버 럭 구매가 모두 서버 공지로 나갑니다. 다른 유저에게 "나도 갖고 싶다"는 마음을 만듭니다.
3. **무과금 유저도 경쟁 가능.** 주간 랭크와 운석 점수가 압축되어 있어 무과금 유저가 남고, 유저 풀이 유지되어야 과금 유저도 남습니다.
4. **정책 준수.** 확률 공개, PolicyService, 영수증 중복 방지(PurchaseId 기록), 세션 락으로 아이템 복사를 막았습니다.

- 개발자 몫은 게임패스·개발자 상품 가격의 **70%**입니다. 이 Robux를 DevEx로 환전하면 **$0.0038/Robux**입니다.
