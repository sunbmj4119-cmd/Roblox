# 04. 현실적인 수익 전망 & 스튜디오 기본 세팅

## Part 1. 현실 점검: 대부분의 게임은 뜨지 못합니다

| 지표 (2026) | 수치 |
|---|---|
| 로블록스에 있는 게임 수 | 약 850만 개 이상 |
| 어느 순간에 동접 0명인 게임 | **99.8%** (동접 1명 이상은 약 1만 8,500개) |
| 동접 1,000명 이상 | 1,400개 미만 (상위 약 0.02%) |
| 동접 1만 명 이상 | 112개 |
| 동접 상위 100개 게임의 점유율 | 전체 동접의 약 50% |
| DevEx로 환전한 개발자의 중간값 | 연 약 $1,500 (3만 Robux를 못 모아 환전도 못 한 사람은 제외한 수치) |
| 플랫폼 상황 (2026년 3분기) | 일일 유저 1억 3,800만 명 (전년보다 9% 감소), 매출(bookings) 12% 감소, 결제 유저 16% 감소 → 2025년 대유행 이후 식는 중 |

### 동접별 예상 월수익 (제3자 추정: 동접 1명당 월 $2~3 수준)
| 평균 동접 | 예상 월수익 (세전) | 현실성 |
|---|---|---|
| 0~10명 | $0~30 | 홍보 없이 올리면 대부분 여기서 끝남 |
| 100명 | $200~300 | 꾸준한 업데이트 + 소액 광고로 노려볼 만함 |
| 1,000명 | $2,000~3,000 | 상위 0.02%. 썸네일·리텐션·운이 모두 맞아야 함 |
| 10,000명 | $20,000~30,000 이상 | 최상위 100여 개 게임 |

> 위 숫자는 로블록스 공식 통계가 아니라 외부 추정치이고, 장르·결제 설계에 따라 몇 배씩 차이가 납니다. 시뮬레이터 장르는 평균보다 결제가 잘 일어나는 편입니다.

### 이 게임의 강점과 약점 (솔직한 평가)
**강점**
- 수익화·경쟁·리텐션 시스템이 상위 게임 수준으로 갖춰져 있습니다.
- 설정 파일만 고치면 콘텐츠를 계속 추가할 수 있습니다.

**약점 (못 뜰 위험 요인)**
1. **그래픽이 기본 블록 수준입니다.** 썸네일·아이콘 클릭률이 노출 알고리즘에 큰 영향을 주는데, 지금 상태로는 경쟁이 어렵습니다. → 펫·광석 3D 모델과 아이콘·썸네일 아트에 투자가 필요합니다.
2. **채굴 시뮬레이터는 이미 수천 개가 있습니다.** 운석 레이드와 주간 랭크가 차별점이지만, 썸네일 한 장으로 그 차별점이 보여야 합니다.
3. **2026년 규정상 처음에는 16세 이상에게만 노출됩니다.** 시뮬레이터의 핵심 유저층(9~15세)에게 노출되려면 별도 조건을 통과해야 합니다.
4. 플랫폼 전체 유저가 줄고 있어 신규 게임 간 경쟁이 더 치열합니다.

### 추천 전략: 작게 시험하고 숫자를 보고 결정
1. **소프트 런칭:** 공개 후 Ads Manager로 $50~100만 써서 유저 수백 명을 데려옵니다.
2. **핵심 지표 확인** (Creator Hub → Analytics)
   - D1 리텐션(다음 날 재방문율): **15% 미만이면** 광고를 늘리지 말고 초반 경험부터 고칩니다.
   - 평균 플레이 시간: 15분 이상이 목표입니다.
   - 결제 전환율, ARPDAU(하루 유저 1명당 평균 매출)
3. **지표가 괜찮으면** 아트를 업그레이드하고 광고를 늘리고 주 1회 업데이트합니다.
4. **지표가 나쁘면** 같은 코드로 콘셉트(테마·훅)만 바꿔서 다시 시험합니다. 대부분의 성공작이 이런 반복으로 나옵니다.

## Part 2. 로블록스 스튜디오 설치 & 기본 세팅

### 1. 설치
- **필요 사양:** Windows 10 이상 또는 macOS 10.14 이상, 메모리 3GB 이상 (권장 8GB, Windows 11 / macOS 14)
- **순서:**
  1. create.roblox.com에 접속해 로그인하고 **Studio 다운로드**를 누릅니다.
  2. 받은 설치 파일(Windows는 `.exe`, Mac은 `.dmg`)을 실행합니다.
  3. 스튜디오가 열리면 로블록스 계정으로 로그인합니다.

### 2. 게임 파일 받기
1. GitHub 저장소(sunbmj4119-cmd/Roblox)에서 `MeteorMiners.rbxlx`를 누릅니다.
2. 오른쪽 위 **다운로드 버튼(Download raw file)**을 누릅니다.
3. 스튜디오에서 **File → Open from File**을 누르고 받은 파일을 엽니다.

### 3. 처음 테스트
- **Play** 버튼(F5)을 누르면 혼자 테스트합니다. 끝낼 때는 **Stop**(Shift+F5)을 누릅니다.
- **Output 창 켜기 (중요):** View 탭 → Output. 빨간 에러가 보이면 **그 내용을 복사해서 저에게 보내 주세요.**
- **폰 화면 미리보기:** Test 탭 → Device에서 iPhone이나 안드로이드 기종을 고르면 모바일 화면으로 볼 수 있습니다.
- **여러 명 테스트:** Test 탭 → Clients and Servers에서 인원을 2~3명으로 정하고 Start를 누릅니다. PvP와 운석 경쟁을 시험할 수 있습니다.
- 화면 왼쪽 아래 **🛠 DEV** 버튼으로 코인 지급, 운석 소환 등을 할 수 있습니다 (스튜디오에서만 보임).

### 4. 게임 올리기 (Publish)
1. **File → Publish to Roblox**를 누릅니다.
2. **새 게임 만들기**를 선택하고 아래를 입력한 뒤 Create를 누릅니다.
   - 이름, 설명
   - 장르: Simulation
   - 기기: Computer / Phone / Tablet / Console 모두 체크
3. 처음에는 **비공개(Private)** 상태로 올라갑니다. 그대로 두고 아래 설정을 먼저 합니다.

### 5. 기본 설정 (Game Settings)
> 2026년 1월부터 스튜디오 화면 구성이 새 UI로 바뀌어서 메뉴 이름이나 위치가 조금 다를 수 있습니다. Home 탭이나 File 메뉴의 **Game Settings / Experience Settings**를 찾으세요.

| 항목 | 설정 | 이유 |
|---|---|---|
| Security → **Enable Studio Access to API Services** | **켜기** | 스튜디오 테스트에서도 저장과 리더보드가 동작 |
| Security → Allow HTTP Requests | 끄기 (기본값) | 이 게임에서는 필요 없음 |
| Avatar → Avatar Type | **R15** | 미국 18세 이상 결제분 환율 +42% 보너스 조건 중 하나 |
| Places → Max Players (서버 인원) | **20~24명** | 운석 경쟁이 붐비면서도 서버가 버벅이지 않는 인원 |
| Monetization → Private Servers | 켜고 가격 설정 (예: 100 Robux/월) | 추가 수익 (선택) |

### 6. Creator Hub(웹)에서 할 일 (폰으로도 가능)
1. **아이콘(512×512)과 썸네일(1920×1080)**을 올립니다. 클릭률을 가장 크게 좌우합니다.
2. **Maturity & Compliance 설문**을 작성합니다 (공개 필수).
3. **Monetization**에서 게임패스 10개와 개발자 상품 16개를 만듭니다. 생성된 ID를 저에게 알려 주시면 코드에 넣어 드립니다.
4. **Localization**에서 자동 번역을 켭니다 (한국어 등).
5. 준비가 끝나면 공개 여부를 **Public**으로 바꿉니다.

### 7. 수정 후 다시 올리기
상품 ID를 넣는 등 코드를 고치면 `rojo build`로 새 `.rbxlx`를 만들거나 제가 만든 새 파일을 받습니다. 그 파일을 스튜디오에서 열고 **File → Publish to Roblox**로 **기존 게임에 덮어쓰기**를 합니다.
